# Gramup — مینی‌اپ تلگرام

مینی‌اپ تلگرام برای جمع‌آوری پوینت (تسک، ورود روزانه، دعوت دوستان)، تبدیل پوینت به GRAM و درخواست برداشت.
بک‌اند: Node.js + Express + MongoDB. فرانت‌اند: HTML/CSS/JS ساده در `public/` (سه زبان: دری، پشتو، انگلیسی).

## راه‌اندازی

```bash
npm install
cp .env.example .env     # و مقدارها را پر کنید (حداقل BOT_TOKEN، MONGO_URI، ADMIN_KEY)
npm start
```

پنل ادمین: `https://آدرس-شما/admin.html` (با `ADMIN_KEY` وارد می‌شود).

## قابلیت‌های مهم

- **عضویت اجباری در کانال‌ها:** در پنل ادمین، تب «کانال‌های اجباری». ربات باید در کانال **ادمین** باشد.
  عضویت هر بار که مینی‌اپ باز می‌شود دوباره از تلگرام (`getChatMember`) بررسی می‌شود و همه‌ی APIهای محافظت‌شده هم آن را چک می‌کنند.
  اگر بررسی ممکن نباشد، کاربر تایید نمی‌شود (fail-closed).
- **پاداش اولیه Referral:** با ثبت موفق یک رابطه‌ی دعوت جدید، دعوت‌کننده به‌صورت اتمیک ۱۰ پوینت می‌گیرد؛ این پاداش یک‌باره است و شرط انتظار ۷روزه ندارد. مقدار آن در پنل ادمین → تنظیمات قابل‌تغییر است.
- **کمیسیون Referral چندسطحی:** نرخ پیش‌فرض Levelها به‌ترتیب ۱۰٪، ۵٪، ۳٪ و ۲٪ است. کمیسیون فقط از درآمد اصلی مثبتِ task، check-in و جایزه‌ی هفتگی leaderboard محاسبه و در همان transaction ثبت می‌شود. تبدیل، برداشت، اصلاح دستی و پاداش‌های Referral خودشان کمیسیون ایجاد نمی‌کنند. نرخ هر Level از پنل ادمین قابل‌تغییر است (تا ۱۰ Level؛ مجموع نرخ‌ها حداکثر ۱۰۰٪).
- **تسک‌های مرحله‌ای ریفرال:** این قابلیت جداگانه حفظ شده است؛ با دعوت ۱۰، ۲۰، ۵۰، ۲۵۰، ۵۰۰ و ۱۰۰۰ کاربر فعال، به‌ترتیب ۵۰، ۱۵۰، ۳۰۰، ۱۰۰۰، ۲۵۰۰ و ۵۰۰۰ پوینت قابل Claim می‌شود.
- **مدیریت موجودی و حساب:** از تب «کاربران»، جزئیات حساب، مجموع امتیازها/GRAM، تاریخچه‌ی تراکنش‌ها، وضعیت Fraud/Manual Review و عملیات تکی یا گروهی موجودی در دسترس است. هر تغییر موجودی با دلیل اجباری، Action ID و Audit ثبت می‌شود؛ صفرکردن تأیید جداگانه دارد.
- **برداشت:** همیشه دستی توسط ادمین بررسی و تایید می‌شود.

## مهاجرت Referral v2

مهاجرت به‌صورت خودکار هنگام شروع سرور اجرا نمی‌شود. ابتدا نسخه پشتیبان از MongoDB بگیرید و در صورت امکان هنگام توقف نوشتن‌های برنامه، گزارش dry-run را اجرا کنید:

```bash
npm run migrate:referral-v2
```

این دستور فقط رابطه‌های قدیمی را از `User.referredBy` می‌خواند و تعداد رابطه‌های قابل‌ساخت، زنجیره‌های حلقه‌ای و والدهای مفقود را گزارش می‌کند. برای اجرای واقعی، فقط پس از بررسی گزارش و داشتن backup از گزینه‌ی صریح استفاده کنید:

```bash
npm run migrate:referral-v2 -- --apply
```

Migration تکرارپذیر است و موجودی یا Ledger تاریخی را تغییر نمی‌دهد؛ به کاربران قدیمی پاداش اولیه یا کمیسیون گذشته‌نگر نمی‌دهد. تراکنش‌های مالی Referral v2 به MongoDB Replica Set/Atlas نیاز دارند، مانند سایر عملیات حساس مالی پروژه.

## ساختار پوشه‌ها

| مسیر | توضیح |
|---|---|
| `server.js` | راه‌اندازی Express، middlewareها، مسیرها |
| `routes/` | APIها (auth، tasks، points، referral، leaderboard، membership، admin، telegramWebhook) |
| `models/` | مدل‌های Mongoose |
| `utils/` | احراز هویت تلگرام، ربات، منطق عضویت (`membershipCore.js`) (`spin.js`) و ... |
| `public/` | مینی‌اپ (`index.html`, `js/`, `css/`) و پنل ادمین (`admin.html`) |
| `tests/` | تست‌های منطق سرور (بدون نیاز به دیتابیس) |
