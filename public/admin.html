افزودن تسک جدید

Latest Post Engagement فقط با reaction واقعی کاربر به آخرین پست ثبت‌شده در webhook تأیید می‌شود؛ برای آن ربات باید در کانال Admin باشد.

⚠️ ربات باید ادمین همین کانال/گروه باشد. فرمت و دسترسی chat از طریق Telegram API در «تست chatId» بررسی می‌شود؛ پیشوند خاصی برای ID عددی اجباری نیست.

پاداش فقط وقتی پرداخت می‌شود که webhook تغییر reaction همین کاربر را برای آخرین پست ثبت کرده باشد. دریافت `channel_post` و `message_reaction` با تنظیم webhook فعال می‌شود؛ پست قدیمی قابل بازیابی نیست.

اگه پر کنی، فقط همین تعداد نفر اول که تسک رو با موفقیت انجام بدن پاداش می‌گیرن؛ بعدش تسک خودکار غیرفعال می‌شه.

یک تبلیغ‌دهنده برای هر عضو تاییدشده مبلغی می‌پردازد. ظرفیت این تسک خودکار از «بودجه ÷ قیمت هر عضو» محاسبه می‌شود و شما نباید حداکثر تکمیل را جدا وارد کنید.

⏰ Daily Check Reminder (یادآوری ورود روزانه)

به کاربرانی که آن روز هنوز ورود روزانه نزده‌اند، یک‌بار در روز پیام یادآوری فرستاده می‌شود (به زبان خودشان، مگر متن سفارشی زیر را پر کنید). سرور هر ۱۰ دقیقه چک می‌کند و فقط در همان ساعتی که اینجا تنظیم می‌شود ارسال می‌شود؛ بعد از ذخیره، زمان‌بندی خودش از تنظیمات جدید استفاده می‌کند و نیازی به ری‌استارت نیست.

پیش‌نمایش:
این عملیات فقط پیام آزمایشی می‌فرستد، پاداش یا وضعیت Daily Check را تغییر نمی‌دهد و نتیجه ارسال در همان‌جا نمایش داده می‌شود.

Referral — پاداش و کمیسیون

پاداش مستقیم برای هر دعوت معتبر دقیقاً ۱۰ Points است. کمیسیون فقط از Points واقعاً کسب‌شده در task، check-in و leaderboard محاسبه می‌شود؛ تبدیل موجودی و پاداش‌های Referral کمیسیون ایجاد نمی‌کنند.

🏆 Weekly Leaderboard

امتیازها هر دوشنبه بر اساس UTC از صفر محاسبه می‌شوند. جوایز زیر برای رتبه‌های اول تا سوم است و می‌تواند از بودجه‌ی تبلیغ‌دهنده تأمین شود.

💎 Native GRAM Deposit — TON Mainnet

این Deposit فقط ارز بومی GRAM شبکه TON را می‌پذیرد و از Jetton یا Jetton Master استفاده نمی‌کند. آدرس عمومی کیف‌پول پروژه را از منبع مورداعتماد وارد کنید؛ هر کاربر باید Reference اختصاصی را در comment تراکنش Native GRAM بنویسد. این برنامه seed یا private key نگهداری نمی‌کند. Deposit به‌صورت پیش‌فرض خاموش است.

برای روشن‌کردن، آدرس معتبر TON Mainnet و حداقل مبلغ Native GRAM لازم است. برنامه هیچ کلید یا عبارت بازیابی کیف‌پول را نگهداری نمی‌کند.
